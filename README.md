## Опис проєкту

Репозиторій містить інструкції для AI-агента VS Code Copilot, який створює
кросплатформний Rust-проєкт Hello World із Cargo, тестом `basic_addition` і CI
на GitHub Actions для Windows, Linux та macOS.

## Запуск агента

1. Відкрийте папку репозиторію у VS Code.
2. Відкрийте Copilot Chat.
3. Виберіть агента `build-engineer`.
4. Виконайте команду `/init`.

## Commands

- `/git-init` — перевірити Git-репозиторій і створити або доповнити `.gitignore`.
- `/create-project` — створити початковий каркас Rust-проєкту.
- `/create-build` — налаштувати Cargo, тест і кросплатформні скрипти збірки.
- `/create-actions` — створити GitHub Actions workflow.
- `/check` — перевірити структуру, збірку, тести та CI без зміни файлів проєкту.
- `/init` — послідовно виконати початкове налаштування та фінальну перевірку.
